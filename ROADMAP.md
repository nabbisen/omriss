# Roadmap

The authoritative roadmap, milestone definitions (M0–M9), and theme
breakdown live in the design documents:

- RFC index: [`rfcs/README.md`](rfcs/README.md)
- Lifecycle policy: [`rfcs/done/000-rfc-lifecycle-policy.md`](rfcs/done/000-rfc-lifecycle-policy.md)

Status snapshot (v0.14.0+): RFCs 000–047 are implemented; M0–M9 themes are
complete. The desktop MVP runs on Linux/macOS/Windows (the desktop shell
requires platform WebView libraries to build — see `PLATFORMS.md`). The
outline/tree UI uses `dioxus-swdir-tree`.

Current proposed roadmap work is tracked in [`rfcs/README.md`](rfcs/README.md).
At this snapshot, RFC-048 through RFC-058 are proposed for M10–M14:

- M10: RFC-048 through RFC-051, UI role separation.
- M11: RFC-052 and RFC-053, structured plain-text policy and adapter foundation.
- M12: RFC-054 through RFC-056, JSON/TOML/YAML follow-up work.
- M13: RFC-057, multi-document workspace and tabs.
- M14: RFC-058, placement-complete Document Map creation controls.

The RFC index is authoritative for exact titles, lifecycle state, and next free
RFC number.
