# Introduction

**omriss** (Omriss Editor) helps you clarify ideas and refine them,
consideration by consideration — *layer by layer*.

A Markdown document is more than a wall of text: its headings form a stack of
layers. omriss makes that structure the way you work. The Document Map is
where you navigate and organize those layers; the Writing Area is where you
focus on one section, refine it, and leave confident that nothing else in the
file changed.

Markdown is where omriss starts, not where it stops. The same layer-by-layer
idea applies to other structured plain-text files — configuration, settings,
and data files people already keep in JSON or TOML — and omriss is growing to
meet them there, without ever asking you to give up the plain-text file
itself. See [File Formats](file-formats.md) for what is supported today.
